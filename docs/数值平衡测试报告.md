# Rush 构筑与里程碑数值平衡测试报告（历史专项）

> 本文保留为 2026-09-29 的历史专项记录，其中 ×3 Rush 与旧阶段表不再是当前正式值。当前结论与正式配置以 `Docs/Balance/` 下的 Baseline、Proposal 和 Changelog 为准。

## 1. 本轮目标

本轮调整围绕一条明确体验曲线：第 1 关中等难度，第 2～3 关形成构筑压力；玩家完成 Rush 核心后，阶段目标仍增长，但相对压力持续下降，让高投入爆发、装置联动和药物时机共同产生爽感。

验收不只看总分，还看以下指标：

- 开局构筑的 P10 低于第 1 阶段目标、P50 高于目标，避免必过或大面积卡死。
- Rush 核心构筑的中位产出至少为开局构筑的 1.6 倍。
- 成型构筑的中位产出至少为开局构筑的 4 倍。
- 正确择机用药相对开局全吃，平均产出至少高 8%，P90 爆发至少高 15%。
- 第 2～3 阶段形成压力峰值，第 4～6 阶段压力连续下降。

## 2. 关键修改

| 模块 | 调整后 | 设计目的 |
| --- | --- | --- |
| 高流量 | 球价值按 `投入量^1.15` 增长，半径按投入量立方根增长，质量线性增长 | 低流量负责多次 Rush 尝试，高流量负责 Rush 窗口爆发 |
| Rush 基础 | 高倍区基础概率 12%，槽阈值 8，持续 5 秒，上限 8 秒，倍率 ×3 | 给玩家多 25% 的切档与用药操作窗口 |
| Rush Ding | 18 金币，单件 +12 个百分点 | 形成可叠加的稳定触发路线 |
| 黑色四叶草 | 24 金币 | 让强触发组件更早进入构筑期 |
| 增值透镜 | 36 金币 | 控制价值倍增进入中后期，但不拖到流程结束 |
| 肾上腺素 | 开局 1 个；22 金币；6 秒；Rush 概率 +25%；血耗 ×1.15 | 在 Rush 槽接近阈值时主动点火 |
| 烧烧果实 | 18 金币；6 秒；基础价值 ×0.90；Rush 内额外 ×1.75 | 用错时机亏 10%，命中窗口获得显著爆发 |
| 延长药剂 | 24 金币；6 秒；Rush 时长 ×1.50，即 7.5 秒；血耗 ×1.15 | 在槽接近阈值时为触发球预埋更长窗口 |
| 商店 | 每轮至少 1 个 Rush 装置、1 个 Rush 药物，其余槽位随机；同轮不重复 | 避免玩家因纯随机完全无法构筑 |

药物影响的是使用后新发射的球，不会追溯修改已经在场的球。推荐操作节奏是：平时低流量积累触发次数，槽值接近 5/8 时使用肾上腺素和延长药剂；Rush 开启后立刻使用烧烧果实并切到高流量。

### 2.1 其余装置与药物的静态审计

全目录 34 个属性、15 种装置和 12 种药物均通过 ID、范围、库存和价格校验。非 Rush 内容中，以下关系最值得在实机数据中继续观察：

| 内容 | 静态结论 | 验收重点 |
| --- | --- | --- |
| 凝血剂 / 摇头丸 / 稀血剂 | 价值 ×1.30、血耗 ×1.20，未计功能前每血价值约 +8.3% | 体积、弹性、穿透是否让实际命中收益过高 |
| 润流剂 / 定向试剂 | 基础价值 ×0.90 | 路线改善至少要带来 11.1% 的命中提升才不亏 |
| 磁堕 | 价值 ×1.10、血耗 ×1.20，每血价值约 -8.3% | 磁力路线需要补回这部分损失 |
| 无限增值 | 初始价值效率只有 50%，但复制可在后续接触继续传播 | 重点压测 256 球上限、帧率和指数复制路径 |
| 增幅塔 | 两塔成线总门槛 36 金币，每次过线 ×1.20，可重复过线 | 与同价增值透镜的单次 ×2 形成路线型差异 |
| 资本主义 | 价值至少 6 才生效；5 档无药球价值约 6.36 | 现在与高流量形成明确门槛组合 |
| 银行 | 当前价值乘 0.12 后向下取整，高流量裸球仍为 0 金币 | 应定位为价值构筑终点，不是新手通用经济装置 |
| 赌博区 | 名义期望倍率 1.75，但高倍普通区为 ×10 | 只有更高命中率或赌池构筑才能补偿名义差距 |

这些项目没有在缺少物理命中率的情况下被强行改价。先用遥测验证其路线收益，再决定是否调整；其中“无限增值”的性能和指数复制风险优先级最高。

## 3. 模型范围与假设

测试脚本为 `Tools/Balance/rush_balance_model.py`，直接读取运行时 JSON 和场景中的非零 Rush 基础概率。固定种子下运行 10,000 局/构筑。

上一版结算层模型高估了绝对得分：实机反馈表明首关 1000 分不可达，150 分接近合理。当前模型因此将抽象结算分统一乘以 `0.15`，用首关 150 分校准绝对尺度，同时保留不同构筑、药物时机之间的相对差异。这个系数只是一处实机锚点，不等同于完整物理遥测。

物理路线尚无项目遥测，因此使用显式假设：

| 去向或事件 | 概率 |
| --- | ---: |
| ×10 Rush 得分区 | 30% |
| ×1 普通得分区 | 50% |
| 赌博区 | 10% |
| 落空/回收 | 10% |
| 单个普通装置命中 | 55% |
| 四叶草命中 | 45% |
| 增值透镜命中 | 30% |
| 飞行时间 | 1.8～3.2 秒均匀分布 |

这是一套结算层模型，用于比较方案，不等价于 Unity 物理实机结果。取得 Play Mode 命中率与每局实际分数分布后，应同时替换上述路线参数和 `OBSERVED_SCORE_SCALE`，再重新跑同一组门槛。

## 4. 10,000 局模拟结果

| 构筑 | 平均分 | P10 | P50 | P90 | Rush 得分占比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无构筑 | 127 | 94 | 126 | 159 | 83.5% |
| 开局 Multi | 197 | 145 | 195 | 250 | 83.5% |
| 开局 Multi + 肾上腺素 | 248 | 137 | 241 | 368 | 89.1% |
| Rush 起步（保守：Rush Ding + 延长） | 259 | 146 | 254 | 380 | 90.6% |
| Rush 核心，开局把药全吃 | 316 | 186 | 307 | 461 | 97.6% |
| Rush 核心，按槽值/Rush 择机用药 | 373 | 186 | 359 | 578 | 93.5% |
| Rush 强化 | 612 | 303 | 591 | 945 | 94.3% |
| Rush 成型 | 916 | 500 | 892 | 1353 | 97.6% |
| Rush 豪华 | 1064 | 590 | 1036 | 1567 | 97.6% |
| Rush 超载 | 1714 | 959 | 1661 | 2538 | 98.7% |

择机用药相对开局乱吃，平均分提高约 17.8%，P90 提高约 25.4%。两种方案的 P10 接近，但正确时机明显提高中位和高爆发收益，药物窗口仍然具备操作价值。

Rush 核心的中位产出约为开局 Multi 的 1.84 倍；Rush 成型约为 4.57 倍；超载约为 8.51 倍。目录完整性、首轮购买力、Rush 时长空间和七项体验门槛共十项自动检查全部通过。

## 5. 非线性里程碑

| 阶段 | 累计目标 | 目标增量 | 推荐构筑基线 | 预计本轮中位分 | 压力系数 |
| ---: | ---: | ---: | --- | ---: | ---: |
| 1 | 150 | 150 | 开局 Multi + 肾上腺素 | 241 | 0.62 |
| 2 | 450 | 300 | Rush 起步（保守药物） | 254 | 0.83 |
| 3 | 960 | 510 | Rush 强化 | 591 | 0.79 |
| 4 | 1650 | 690 | Rush 成型 | 892 | 0.63 |
| 5 | 2520 | 870 | Rush 豪华 | 1036 | 0.52 |
| 6 | 3750 | 1230 | Rush 超载 | 1661 | 0.44 |

压力系数按“从预计累计分起点到本阶段目标还缺的分数 ÷ 本轮构筑中位产出”计算，因此已经考虑上一关的常见超额分。目标增量始终上升，但构筑成长更快：第 2～3 关是构筑峰值，之后连续释放压力。

阶段奖励同步调整为 `35/45/60/80/105/135`，保证商店保底出现后通常可以买到至少一个核心组件或药物。越级追加为 `18/22/30/40/52/68`。

- 10,000 局/构筑固定种子 Monte Carlo：十项自动检查全部通过。
- Excel 最终渲染检查：阶段表结构和格式正常。

## 7. Play Mode 验收清单

首关 150 分已经采用本次实机反馈作为校准锚点。当前执行环境未检测到 Unity Editor，因此其余物理盘面、碰撞路线和 UI 手感仍需在 Unity 中完成最后一轮验收：

1. 执行 `Marbles ECS → Validate Attribute and Content Runtime`，确认全部断言通过。
2. 连续玩 20 局新档，记录每阶段通关率、终点命中率、Rush 时间占比和药物使用时刻。
3. 第 1 阶段目标通关率建议 65%～85%；第 2～3 阶段允许降到 50%～70%；第 4 阶段后应明显回升。
4. 对同一 Rush 核心盘面各跑 20 局“开局乱吃”和“按槽值/Rush 择机”，正确时机的均值应至少高 8%。
5. 检查 Rush 开启后切 5 档流量是否能在 5～7.5 秒内形成明显的音画和分数峰值；若普通窗口仍来不及完成切档和发射，再考虑小幅增加上限，不要优先抬倍率。
6. 若第 2 关失败主要来自商店选择而不是操作，先检查玩家是否能理解保底槽和药物用途，再考虑下调目标。
