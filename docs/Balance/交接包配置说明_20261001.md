# 《血色柏青哥》Balance V6 程序交接说明

交接日期：2026-10-01  
模拟 Seed：`20260930`  
正式阶段目标：`120 / 380 / 815 / 1410 / 2200 / 3145`

## 1. 安装方式

1. 关闭 Unity，或至少退出 Play Mode。
2. 将压缩包解压到临时目录。
3. 把压缩包内的 `Assets`、`Tools`、`docs` 三个目录复制到 Unity 项目根目录。
4. 选择“合并目录并覆盖同名文件”，不要先删除项目中原有目录。
5. 重新打开 Unity，等待脚本编译及资源导入完成。

压缩包保留了原项目相对路径，同时包含 Unity `.meta` 文件，禁止只复制 `.cs` 而遗漏同目录的 `.meta`。

## 2. 配置来源优先级

运行时 Source of Truth：

1. `Assets/Resources/GameContent.json`：属性、装置、药物、价格、效果和内容规则。
2. `Assets/Resources/GameBalance.json`：血量、发射档位、库存、商店刷新、阶段目标和战役规则。
3. `Assets/Scenes/TestScene.unity`：盘面 Collider、Zone、Launcher 和场景绑定。

Excel 是策划编辑入口；JSON 是 Unity 实际读取结果。修改 Excel 后必须确认对应 JSON 已成功更新。

## 3. 日常修改入口

### 3.1 回合与基础经济

编辑：`Assets/Config/GameBalance.xlsx`

- `Stages`：各回合累计目标、基础奖励、越级奖励、Cashout Rate。
- `Campaign`：金币、商店、刷新及战役规则。
- `Marble`：血量、发射档位、发射间隔和基础运行参数。

保存后 Unity 会自动尝试导入；也可手动执行：

`Marbles ECS/Import Game Balance Excel`

输出文件：`Assets/Resources/GameBalance.json`

### 3.2 装置、药物和内容属性

编辑/审阅：`Assets/Docs/血色柏青哥_道具药物装置_规范修订版.xlsx`

- `运行时平衡表`：交接总览，列出 27 个装置/药物的正式价格、效果、证据等级及改动原因；该页不被 Importer 读取。
- `设计总表`：名称、说明、持续时间、叠加规则等可导入字段。
- 属性字典/属性页：基础属性和药物属性数值。
- `效果参数`：配方说明和策划审阅数据。

显式导入菜单：

`Marbles ECS/Import Attribute and Content Excel`

输出文件：`Assets/Resources/GameContent.json`

装置行为配方仍以已注册 JSON/代码为准。不要只修改自然语言说明来改变玩法；Importer 会拒绝说明与已注册行为不一致的发布。

- Unity PhysX 不保证跨平台位级一致；复现时必须保留 Seed、Unity 版本和盘面配置。
