# 装置一览

当前共 35 种：普通 12、罕见 18、稀有 5、传奇 0。

| 稀有度 | Metadata rarity | 基础购买价 | 档位抽取权重 |
|---|---|---:|---:|
| 普通 | common | 9 | 60% |
| 罕见 | uncommon | 14 | 30% |
| 稀有 | rare | 23 | 7% |
| 传奇 | legendary | 38 | 3% |

价格指一次购买的 `metadata.purchasePrice`，传送门 14 金币获得一对。出售其中一扇会移除整对，按 `metadata.value` 发放一次金币。把其中一扇投喂给大胃袋时也会消耗整对，只获得一次该稀有度的成长。商店价格修正照常应用。

每个货位先按有货档位的权重抽取稀有度，再在该档尚未出现的装置中等概率选择；同一批商品不重复。某档没有装置或已被抽空时，跳过该档并归一化剩余权重，不留空位、不重抽。当前没有传奇，实际档位概率为普通 60/97 ≈ 61.86%、罕见 30/97 ≈ 30.93%、稀有 7/97 ≈ 7.22%；加入传奇内容后恢复四档比例。

商店和付费刷新都使用此规则。保持整局共享随机序列，每个实际生成的货位仅消耗一次随机数；购买不消耗随机数，目录按 ID 排序，同种子、同操作顺序可重放。开局库存规则见 [数值配置](Balance.md)。

`DeviceRarityRules.cs` 保存标准价格和抽取权重，运行时购买价仍以包内 Metadata 为准。Packer 新建配置默认普通/9，切换稀有度时填入 9/14/23/38；当前所有制作 Profile、成品包和 GameContent 快照已同步。`rare` 现在表示第三档“稀有”，第二档使用 `uncommon`；`epic` 已取消。大胃袋对应四档仍分别获得 +2/+4/+6/+8。

装置的物理反弹在 `Resources/Devices/<id>/device.json` 的 `Bounce` 设置，范围 0～1，缺省为 0。运行时按该值配置实体碰撞体，反弹取它与弹珠当前 `BALL_BOUNCE` 的较大值。主动弹射和改速由各装置 Lua 的效果参数决定。
