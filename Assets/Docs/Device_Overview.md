# 装置一览

当前共 37 种，普通 14、罕见 18、稀有 5、传奇 0。

| 稀有度 | Metadata rarity | 缺省血肉残料安装价 | 档位抽取权重 |
|---|---|---:|---:|
| 普通 | common | 9 | 60% |
| 罕见 | uncommon | 14 | 30% |
| 稀有 | rare | 23 | 7% |
| 传奇 | legendary | 38 | 3% |

装置以 `metadata.biomassScrapPrice` 作为整套残料安装价。历史装置包缺省时使用上表默认值。传送门一套两扇，首次安装计整套价格。允许出售时，出售其中一扇会移除整对，按实付的残料乘以 `Campaign.SellRatio` 后向下取整，返还一次。把其中一扇投喂给大胃袋时也会消耗整对，获得一次该稀有度的成长。

每个货位先按有货档位的权重抽取稀有度，再在该档尚未出现的装置中等概率选择；同一批商品不重复。某档没有装置或已被抽空时，跳过该档并归一化剩余权重，不留空位、不重抽。当前没有传奇，实际档位概率为普通 60/97 ≈ 61.86%、罕见 30/97 ≈ 30.93%、稀有 7/97 ≈ 7.22%；加入传奇内容后恢复四档比例。

商店和付费刷新共用此抽样规则。每个实际生成的货位消耗一次共享随机数，目录按 ID 排序。每日权限商店还可修改当天的权重、候选池和保证货位。配置见 [每日内容制作指南](DayFramework_Content_Guide.md)。

调安装价和耐久使用包内 `metadata.json`，调效果参数使用 `device.json`。三种钉子的 `Bounce` 都是 0.8，沿盘面的碰撞半径都是 0.40，摆放占地半径约为 0.585。

`DeviceRarityRules.cs` 保存缺省安装价和默认抽取权重。每日权限的工票解锁价取当天的 `shopDrawCost`。大胃袋按四档稀有度分别获得 +2/+4/+6/+8 成长。

装置的物理反弹在 `Resources/Devices/<id>/device.json` 的 `Bounce` 设置，范围 0～1，缺省为 0。运行时按该值配置实体碰撞体，反弹取它与弹珠当前 `BALL_BOUNCE` 的较大值。主动弹射和改速由各装置 Lua 的效果参数决定。
