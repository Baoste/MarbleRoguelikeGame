# 装置资源

当前共 40 种装置。[GameContent.json](../GameContent.json) 的 `Devices` 列出游戏启用的装置 ID。每个 ID 是唯一正整数，与子目录名称和 `device.json.Id` 一致。

## 添加或更新装置

以 [9037 三重分裂钉子](9037/manifest.json) 为模板。资源放在 `Assets/Resources/Devices/<id>/`，并提交 Unity 生成的资源和目录 `.meta` 文件。

| 文件 | 用途 |
| --- | --- |
| [`manifest.json`](9037/manifest.json) | 版本 `1`，`name` 为包名，`metadata`、`device`、`prefab`、`lua` 填写同目录的文件名。配有图标时填写 `"icon": "icon.png"`。 |
| [`metadata.json`](9037/metadata.json) | 界面文案、残料安装价、稀有度、耐久和资源类型。 |
| [`device.json`](9037/device.json) | 装置 ID、物理参数、库存套数、摆放规则及 Lua 参数。 |
| [`prefab.prefab`](9037/prefab.prefab) | 原生 Unity Prefab 或 Prefab 变体，持有模型、材质和实体碰撞体引用。根节点的直接子节点 `PlacementVolume` 使用一个禁用的 SphereCollider 定义摆放占地。 |
| [`main.lua`](9037/main.lua) | 以 UTF-8 保存的玩法脚本，由 Unity 导入为 TextAsset。 |
| [`icon.png`](9037/icon.png) | 选配的界面图标。当前 `9033` 至 `9037` 提供图标。 |

模型、材质、贴图和装置预览场景存放在 `Assets/Art/Devices`。库存 UI 卡片使用 [DeviceItem.prefab](../../Prefabs/DeviceItem.prefab)。

新增装置时把 ID 加入 `GameContent.json.Devices`，停用时从列表移除。游戏在下一次进入 Play 或启动时重新加载目录。每日玩法的候选池与权限由 `GameDays.json` 的日期配置决定。详见 [每日内容制作指南](../../Docs/DayFramework_Content_Guide.md#背包与权限商店)。

### 元数据

| 字段 | 用途 |
| --- | --- |
| `name`、`description` | 界面显示的名称与简短描述。 |
| `biomassScrapPrice` | 整套装置的血肉残料安装价，填写正整数。旧包缺省时取同稀有度的库存购买基价。 |
| `rarity` | `common`、`uncommon`、`rare`、`legendary`。默认 `common`。 |
| `durability` | 每回合有效作用次数，默认 `20`，`-1` 表示无限。 |
| `type` | 装置固定填写 `"device"`。 |

每日商店的工票解锁价取当天的 `shopDrawCost`。独立库存商店按稀有度定购买基价，出售返还按库存记录的购入金额和 `Campaign.SellRatio` 计算。见 [装置一览](../../Docs/Device_Overview.md)。

### 玩法配置

| 字段 | 用途 |
| --- | --- |
| `Id`、`SourceId` | 数字 ID 和来源标识。新装置可沿用包名作为来源标识。 |
| `Bounce` | 实体反弹系数，范围为 0 至 1。碰撞时取此值和弹珠当前弹性中的较大值。 |
| `ScoreMultiplier` | Lua 读取的完整得分倍率。单次乘以 1.5 就填写 1.5，除以 2 就填写 0.5。碰撞记录各次因子，进入得分区时按乘积结算。 |
| `StartingCount`、`PurchaseQuantity` | 库存模式下的开局赠送套数、每次购买获得的实例数。当前 `StartingCount` 均为 0，传送门一套 2 扇并自动配对。 |
| `Cooldown`、`MaxTriggersPerBall` | `Trigger` 和 `TryPrepareTrigger` 使用的公共冷却秒数及每球触发上限，`MaxTriggersPerBall = 0` 表示不限次数。 |
| `Value`、`Strength`、`Range` | 分别通过 `api.Parameter`、`api.Strength`、`api.Range` 读取，由 Lua 定义含义。 |
| `RotationLocked` | 为 `true` 时将装置摆放角度锁定为 0。 |
| `LinkGroup`、`GroupClearance` | 连接组名及同组放置间距。 |
| `AcceptsPlacedOffers` | 允许 Lua 的 `OnOffer` 接收盘面上的装置。 |
| `Kind`、`RushChanceAdd`、`RushCategory` | 旧装置沿用的分类和兼容字段。 |

例如 9037 的 `Value = 2` 是复制数量，`Strength = 42` 是出射角间隔，`biomassScrapPrice = 6` 是安装价。具体实现见 [三重分裂钉子 Lua](9037/main.lua)。

## Lua 事件与耐久

每个库存实例拥有独立 Lua 环境，共享 xLua VM。预览关闭碰撞体，正式视图与实例共用脚本状态。`OnContact(api)` 处理接触，`OnField(api)` 处理力场。延时效果通过回调传入的 `api` 继续处理。完整回调、参数映射及示例见 [装置 Lua API](../../Docs/Device_Lua_API.md) 和 [装置 Lua 示例](../../Docs/Device_Lua_Examples.md)。

即时效果在有效作用时用 `Trigger` 或 `TryUse` 登记，持续力场按每球每次进入登记。黏黏每颗释放、吸吸每批释放、大炮每批成功发射、黑洞每次启动各扣 1 耐久。充能、储存、取消和空点击期间保留耐久。最后一点耐久支持整批或完整持续时间，批次重试可用同一个 `TryUseOnce(key)` 去重。库存模式每回合恢复耐久，每日生产按当天设置处理耗尽装置。

## 检查

- Unity 菜单 `Marbles ECS → Validate Attribute and Content Runtime` 检查装置注册、Prefab、Lua、预览、玩法、库存及商店。
- Unity 菜单 `Marbles ECS → Validate Day Configuration` 检查每日内容引用。
- Unity 菜单 `Marbles ECS → 实体UI → 验证跨回合布置与鼠标点击` 检查 TestScene 的预览、摆放及跨回合交互。
